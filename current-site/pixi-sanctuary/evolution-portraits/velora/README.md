# Velora five-stage sprite artwork

Upload five approved **transparent 1024×1024 PNGs** to this folder on the feature branch:

- `new-bond.png`
- `apprentice.png`
- `guardian.png`
- `ascendant.png`
- `celestial.png`

Do not upload the ZIP itself. Do not overwrite existing canonical evolution art. Until each new binary is present, its integrity hash recorded in `current-site/source-manifest.json`, and Sanctuary acceptance passes, these sprites must not be promoted to live.

Walking frames are a separate approval process requiring four individually aligned PNGs per stage; portraits here must not be represented as walking frames.
