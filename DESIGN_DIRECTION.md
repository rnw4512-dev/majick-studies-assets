# Majick visual direction — approved October 4, 2026

User references: four September 19 screenshots provided October 4. References guide atmosphere; they are not assumed licensed production assets.

The app should feel like an inhabited adult magical university. Use carved dark wood, layered bookshelves, candlelight, moonlit/stained-glass windows, plum velvet, brass, ivy/wisteria, potion bottles, celestial objects, rugs and personal belongings. Favor furnished spaces with depth over isolated fantasy icons on dashboard cards.

- Collegium: grand campus entry; navigation remains obvious.
- Learn Lab: furnished candlelit classroom with desks, chalkboard/teaching surface, parchment, books, tools, and clear chart space.
- Living Grimoire: enchanted working library; rich shelves and magical objects frame readable academic pages.
- Sanctuary: warm inhabited personal dorm; beds, study nooks, favorite objects and interaction anchors use the existing Phaser owner.
- Game Realm: distinct study-game locations within the same university design system.

Keep foreground lesson text, chart axes, menus, focus rings and furniture controls readable. Room atmosphere must not move the reading surface, obscure controls or introduce duplicate render/state owners. Motion should support reduced-motion settings. Preserve the protected Guardian movement assets.

Release work remains ordered: protect saves and verify the study loop first; then apply these room identities through current components. Never restore an old experiment build over the current app.
