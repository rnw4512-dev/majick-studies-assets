## How to use this checklist

Each row is an acceptance work item. Source paths below are relative to current-site/ unless marked otherwise. S = main workspace JSON under moonlit_learning_v1, saved through MajickSaveSafety; P = S.progress[courseId]; A = S.majickAccount; C = S.campus; L = S.legacy. These abbreviations identify persistence domains, not a new schema. Exact leaf fields, dynamic IDs, precedence, historical aliases and event receipts must be verified at implementation. A row marked unchecked is not certified parity. Existing shell route or visual preview is not a working feature. No storage values read; no old code edited. Coverage includes all user-named features and additional owners located in the recursive tree and source inspection; runtime-only behavior, exact nested state, deployed-source differences, and backend implementation remain open. At each phase inspect corresponding owner and source-manifest, compare deployed/frozen behavior, add row-level tests, update this document with evidence. Never delete a legacy feature just because it is hidden or has overlapping wrappers.
