# D772 question language standard

Use the user's supplied 58-item D772 pre-assessment as the language/format reference. Preserve those original source records, chosen answers, correct-answer markings and incomplete-math warnings. Never call Majick-authored questions official WGU questions or claim that matching practice guarantees the actual OA.

For new and revised D772 multiple-choice practice:

1. Use a complete scenario followed by a clear task, normally separated by a paragraph break.
2. Use course terminology consistently: population/sample, parameter/statistic, individual/variable, quantitative/categorical, observational study/experiment, sampling method/bias, representative sample/generalization, association/causation, graphical display/distribution, quartile/interquartile range, sample space/outcome/event, mutually exclusive/intersection/union/complement, dependent/independent events, and expected value.
3. Match observed stem forms where appropriate: “What is the sampling method described in this situation?”, “What is a valid conclusion, based on the study?”, “Which outcomes correspond to the event …?”, and “How should this be interpreted?”
4. Provide four distinct, plausible, parallel options and one defensible best answer. Build distractors from actual misconceptions. Avoid filler choices, accidental equivalent fractions, missing values, obviously absurd options and ambiguous negative phrasing.
5. Distribute correct answers across A–D and preserve answer/option alignment. Store the question revision for new attempts; preserve prior attempts and all original source data.
6. Keep the exam-style language in the question. After submission, connect the key term/task to plain English and explain the mathematical or statistical evidence. Guided help does not certify independent mastery.
7. Use the existing shared bank adapters and generated-question engine. Learn Lab, Study Now and Game Realm must receive the same revised content without separate copies or reward/state owners.
8. Keep contexts varied. Classroom transfer remains valuable, but exam-language preparation should also cover neutral research, surveys, transactions, games and other data scenarios.

Validation must check four unique options, one matching key, complete scenarios/data, correct calculations/set operations, source provenance, and availability through each existing learning/practice intake. Match probability answers numerically as well as textually when checking duplicate options.
